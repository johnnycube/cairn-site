# Security policy

Report suspected vulnerabilities privately through GitHub's "Report a
vulnerability" button on the Security tab, or by email to
`security@johanneskueber.com`. Do not open public issues for security reports.

Reports are acknowledged within a few days. Only the currently deployed site
(https://opencairn.org) is supported.

Vulnerabilities in Cairn itself belong to
[cairn-core](https://github.com/johnnycube/cairn-core).
